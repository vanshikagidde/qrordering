QR Ordering System

A modern QR-based restaurant ordering web application that allows customers to scan a QR code, browse the menu, and place orders directly from their mobile devices without waiting for a waiter.

🚀 Live Demo

🌐 Website:  https://www.qrordering.free.nf

📌 Features
QR Code based table ordering
Digital restaurant menu
Add to cart functionality
Order management system
Responsive design for mobile devices
Simple and user-friendly interface
Fast ordering process

🛠️ Technologies Used
HTML
CSS
JavaScript
PHP
MySQL


📷 Project Overview

Customers can:

Scan the QR code placed on the table
Open the digital menu
Select food items
Place orders directly online

This helps restaurants reduce waiting time and improve customer experience.

⚙️ Installation
Clone the repository
git clone
Move the project to your server directory
Import the database file into MySQL
Configure database connection in PHP files
Run the project using XAMPP/Laragon
